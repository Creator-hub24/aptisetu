If x² − 6x + 1 = 0, what is the value of x⁴ + 1/x⁴?
A34
B1156
C1154
D1150
Show answer & solution

Correct answer: C. 1154

Solution in:
Solution: Divide x² − 6x + 1 = 0 by x: x + 1/x = 6. Then x² + 1/x² = 6² − 2 = 34, and x⁴ + 1/x⁴ = 34² − 2 = 1156 − 2 = 1154.x² − 6x + 1 = 0 को x से भाग देने पर: x + 1/x = 6. तब x² + 1/x² = 6² − 2 = 34, और x⁴ + 1/x⁴ = 34² − 2 = 1156 − 2 = 1154.
