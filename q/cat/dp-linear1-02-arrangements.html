CAT Data Interpretation & Logical Reasoning: Arrangements · DP-LINEAR1-02

TITA · Medium

Data set: Arrangement (Medium)
Arrangement

Six photographs are hung in a single row on a gallery wall, in slots 1 to 6 from left to right, one by each of six photographers. Each photograph is one of three types — portrait, landscape, street — with exactly two of each type.

The following is known:

  • Aditi is in a lower-numbered position than Lokesh.
  • Eshan and Bela have different types.
  • Bhavin's type is portrait.
  • Lokesh and Chirag are not in adjacent positions.
  • Lokesh is in slot 2.
  • The photograph in slot 5 is not portrait.
  • Bela's type is street.
  • The photograph in slot 3 is not portrait.
  • Eshan is in slot 6.
  • The photograph in slot 1 is not landscape.
  • Eshan's type is not landscape.
How many street photographs are in slot 1, slot 2 or slot 3?

Type in the answer (TITA): no options.

Show answer & solution

Correct answer: 2

Solution: Step 1: use "Lokesh is in slot 2." — this fixes: Lokesh is in slot 2. Step 2: use "Aditi is in a lower-numbered position than Lokesh." — this fixes: Aditi is in slot 1. Step 3: use "Eshan is in slot 6." — this fixes: Eshan is in slot 6. Step 4: use "Bhavin's type is portrait." — this fixes: Bhavin's type is portrait. Step 5: use "Bela's type is street." — this fixes: Bela's type is street. Step 6: use "The photograph in slot 1 is not landscape." — nothing is fixed outright yet, but it removes options needed later. Step 7: use "Eshan's type is not landscape." — this fixes: Lokesh's type is landscape; Chirag's type is landscape. Step 8: use "Eshan and Bela have different types." — this fixes: Aditi's type is street; Eshan's type is portrait. Step 9: use "Lokesh and Chirag are not in adjacent positions." — nothing is fixed outright yet, but it removes options needed later. Step 10: use "The photograph in slot 3 is not portrait." — this fixes: Bela is in slot 3. Step 11: use "The photograph in slot 5 is not portrait." — this fixes: Bhavin is in slot 4; Chirag is in slot 5. Final arrangement: slot 1: Aditi (street); slot 2: Lokesh (landscape); slot 3: Bela (street); slot 4: Bhavin (portrait); slot 5: Chirag (landscape); slot 6: Eshan (portrait). Reading off: 2.
