Data set: Table with missing data (Easy)
Table with missing data

The table shows the number of scooters (in hundreds) sold by a dealer network in five zones over three years. Some entries are missing; the row totals and column totals are complete.

202320242025Total
North396?60
South?251470
East?163381
West3023?65
Central31321275
Total16310286351

All values are whole numbers; units: hundred scooters.

Which of the following had the highest value in 2024?
AWest
BSouth
CNorth
DCentral
Show answer & solution

Correct answer: D. Central

Solution: Step 1: fill the blanks from the row totals (each row has one blank): North, 2025 = row total 60 − (39 + 6) = 15; South, 2023 = row total 70 − (25 + 14) = 31; East, 2023 = row total 81 − (16 + 33) = 32; West, 2025 = row total 65 − (30 + 23) = 12. Step 2: check against the column totals: 2023 = 163, 2024 = 102, 2025 = 86 (all match). Step 3: compare the five values in that column. Answer: Central.
