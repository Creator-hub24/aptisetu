Algebra

  • (a + b)² = a² + 2ab + b²
  • a² − b² = (a − b)(a + b)
  • a³ + b³ = (a + b)(a² − ab + b²)
  • a³ − b³ = (a − b)(a² + ab + b²)
  • a³ + b³ + c³ − 3abc = (a + b + c)(a² + b² + c² − ab − bc − ca) If a + b + c = 0, then a³ + b³ + c³ = 3abc.
  • ax² + bx + c = 0: x = [−b ± √(b² − 4ac)] / 2a Sum of roots = −b/a, product = c/a.
  • AM ≥ GM: (a + b)/2 ≥ √(ab) for a, b ≥ 0 Equality when a = b.

Progressions

  • AP: Tₙ = a + (n − 1)d, Sₙ = n/2 [2a + (n − 1)d]
  • GP: Tₙ = arⁿ⁻¹, Sₙ = a(rⁿ − 1)/(r − 1) r ≠ 1.
  • Infinite GP: S = a/(1 − r) |r| < 1.
  • 1 + 2 + … + n = n(n + 1)/2
  • 1² + 2² + … + n² = n(n + 1)(2n + 1)/6
  • 1³ + 2³ + … + n³ = [n(n + 1)/2]²

Logarithms

  • log(mn) = log m + log n, log(m/n) = log m − log n
  • log mᵏ = k log m
  • logₐ b = log b / log a Change of base.
  • a^(logₐ x) = x

Number system

  • N = pᵃ qᵇ rᶜ has (a + 1)(b + 1)(c + 1) factors
  • Sum of factors = [(pᵃ⁺¹ − 1)/(p − 1)] × … Multiply over every prime.
  • HCF × LCM = product (two numbers)
  • Trailing zeros of n! = ⌊n/5⌋ + ⌊n/25⌋ + ⌊n/125⌋ + …
  • Euler: a^φ(n) ≡ 1 (mod n) if gcd(a, n) = 1 φ(p) = p − 1 for a prime p.

Counting & probability

  • ⁿPᵣ = n!/(n − r)!, ⁿCᵣ = n!/[r!(n − r)!]
  • Circular arrangements of n = (n − 1)!
  • Ways to split n identical items among r people = ⁿ⁺ʳ⁻¹Cᵣ₋₁ Each may get zero.
  • P(A ∪ B) = P(A) + P(B) − P(A ∩ B)
  • P(not A) = 1 − P(A)

Geometry & mensuration

  • Triangle: area = ½ab sin C = √[s(s − a)(s − b)(s − c)] s = (a + b + c)/2 (Heron).
  • Equilateral triangle area = (√3/4)a²
  • Interior angle of a regular n-gon = (n − 2) × 180°/n
  • Diagonals of an n-gon = n(n − 3)/2
  • Circle: area πr², circumference 2πr; sector = (θ/360)πr²
  • Sphere V = (4/3)πr³, S = 4πr²; cone V = (1/3)πr²h; cylinder V = πr²h
